# 🔮 Zodiac Trait Generator ✨

A Salesforce Lightning Web Component (LWC) application that identifies a user's zodiac sign based on their birth date and displays personalized zodiac traits, emojis, and insights. The application includes input validation, date validation, and is designed to be deployed on Salesforce Experience Cloud Sites.

## 🚀 Features

- 🧑 Capture user name and birth date
- ✅ Required field validation
- 📅 Prevent future birth date entries
- 🔮 Automatic zodiac sign detection
- 🎭 Display zodiac emoji and personality traits
- ⚠️ User-friendly error notifications
- 🌐 Experience Cloud compatible
- 🎨 Responsive UI using Salesforce Lightning Design System (SLDS)

## 🛠️ Technologies Used

- Salesforce Lightning Web Components (LWC)
- JavaScript (ES6)
- HTML
- CSS
- Salesforce Lightning Design System (SLDS)
- Salesforce Experience Cloud

## 📖 How It Works

- Enter your name
- Select your birth date
- Click **Submit**
- The application validates the input fields
- Ensures the selected birth date is not in the future
- Determines the corresponding zodiac sign
- Displays the zodiac sign, emoji, and personalized trait description

## 🔒 Validations Implemented

- Name cannot be empty
- Birth date cannot be empty
- Future dates are not allowed
- Error messages are displayed when validation fails

## 🌐 Deployment

- Experience Cloud Sites
- Community Pages
- Custom Salesforce Applications
